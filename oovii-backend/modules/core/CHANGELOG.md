## [8.0.0]
- Переход на laravel 8, версия PHP поднята до 7.4
- Добавлен класс-обёртка `WithoutWebPWrapper` для работы с изображениями модели не отдавая webp-версию
- Картинки теперь копируются вместе с моделью. Это поведение можно изменить, выставив в конфиге изображения `'replicate' => false`
- Для компонентов формы `file-uploader`, `image-uploader`, `multiple-inputs` и `slug-input` добавлена возможность пробрасывать свои аттрибуты
- Добавлена возможность копировать мультиязычные поля на форме. Включается с помощью системной переменной `COPY_LANG_FIELDS` в .env
- Добавлен трейт для модели `OrderBySort`, позволяющий одним вызовом `sorting()` сортировать результаты выборки, вместо повторения одной цепочки вызовов
`orderBy('sort')->latest('id')`
- Изменен трейт `GetForSelectTrait` для возможности использования в качестве scope `getForSelect(bool $placeholder = false, $value = 'name', $key = 'id')`
- Расширен класс `SEOTools` для уменьшения дублирующегося кода:
  добавлена возможность заполнять мета-теги используя массив настроек или объект `fill(array|object $data)`;
  установка тегов `prev` и `next`, передавая пагинатор `setPrevNext(PaginatorContract $result)`;
  закрыть текущую страницу от индексации с помощью `noIndex(string $value = 'noindex, follow')`
- Добавлена команда `ReCropSettingImagesCommand` для нарезки изображений, загруженных в настройках
- Произведена оптимизация сканера переводов
- В `WezomAssetManager` добавлена возможность группирования скриптов и стилей для возможности разделения на `admin` и `site`
- Удаление загруженных фото осуществляется без перезагрузки страницы
- Функционал `CheckForSpam` вынесен в отдельный класс-сервис для возможности использования вне своего middleware, реализованы свои исключения
- Добавлен `PhoneMaskService` для объединения в одном месте функционала валидации, маскирования и чистки телефонов для хранения. Формат маски теперь будет передаваться в js-скрипт с бэкенда
- Добавлен метод-геттер `parameter($key, $default = null)` в `AbstractWidget`, устраняющий необходимость прямого обращения к свойству `data`
- Компонент карты переписан на использование драйверов, теперь доступен не только `goggle`
- Добавлена возможность классу виджета возвращать `HtmlString` для рендера, устраняя необходимость в собственном шаблоне `view` при условии полностью динамического содержимого
- Сокращено использование `route_localized` для оптимизации производительности
- Обновление зависимостей
- Кнопка "Посмотреть" адаптирована для мобильных устройств
- Bug fix: исправлена инициализация `tinyMCE`
- Прочие мелки правки и рефакторинг
