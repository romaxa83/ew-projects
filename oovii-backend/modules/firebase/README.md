Модуль для рассылки push-уведомлений через firebase

добавляем данную секцию в .env
```dotenv
FIREBASE_USE=true
FIREBASE_SERVER_KEY=
FIREBASE_SENDER_ID=
FIREBASE_SENDER_URL=https://fcm.googleapis.com/fcm/send
```

#### Использование

уведомления отправляются через события, есть двух видов и имееют такой вид
```phpt
// массовая рассылка
event(new FcmGroupPush(Template::TYPE_COLLECTION, $collection));
// одиночная рассылка
event(new FcmPush($user, Template::TYPE_TEST, $collection));
```
Одиночная рассылка - отправляется одному пользователю, принимает 2 обязательных
аргумента - пользователь, которому будет отправленно сообщение и тип шаблона, а также
1 необязательный - связанная модель

Массовая рассылка - отправляется нескольким пользователям, принимает 1 обязательный
аргумент - тип шаблона, а также 1 необязательный - связанная модель, для массовой рассылки
обязательно нужно указать кто получит сообщения по конкретному шаблону , указывается в
файле firebase/Receiver/ReceiverManager.php

Для каждого сообщения создается шаблон, и ему присваеватся уникальный тип, устанавливаются
шаблоны firebase/Helpers/SetTemplates.php, после записывается в бд командой, также для каждого шаблона
нужно создать файл для парсинга переменых в шаблоне и замене их данными,
создаем их в папке firebase/Templates/Strategies/ , файл должен называтся по названию типа + 'Strategy',
т.е. если тип называется registry то файл RegistryStrategy

В таблицу 'fcm_notifications' - записываются все сообщения, и статус их отправки

Если у пользователя нет FcmToken - сообщение ему не отправиться, также рассылку можно отключить
или отключив шаблон или в настройках проставить false для FIREBASE_USE
