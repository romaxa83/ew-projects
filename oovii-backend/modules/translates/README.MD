## Модуль переводов для мобильного приложения (МП) (translates)

![State](https://img.shields.io/badge/state-done-green)

<p align="right">(<a href="https://bitbucket.org/wezom/oovii-backend/src/develop/#top">return to main</a>)</p>

Добавляет переводы с МП в общую таблицу переводов (namespace = api).
Система оперирует тремя языками ("ru", "kk", "en"), при запросе с МП,
вернет все языки установленные МП, если по какому-то языку
не будет перевода, в ответе будет null. <br>
Данные переводы можно редактировать в админ панели (ключом будет api::site.{alias}).


Структура ответа
```json
{
    "button" : {
        "ru": "кнопка",
        "kk": "кнопка(kz)",
        "en": "кнопка(en)"
    },
    "form" : {
        "ru": "форма",
        "kk": "форма(kz)",
        "en": null
    }
}
```


Структура данных при создании/обновлении, соответственно если перевода
по алиасу нет - то создаст, если есть - то обновит
```json
{
    "button" : {
        "ru": "кнопка",
        "kk": "кнопка(kz)",
        "en": "кнопка(en)"
    },
    "form" : {
        "ru": "форма",
        "kk": "форма(kz)",
        "en": "форма(en)"
    },
    "image" : {
        "ru": "картинки",
        "kk": "картинки(kz)",
        "en": "картинки(en)"
    }
}
```

в ответ вернет хеш данных
```json
{
    "data": "bc1d0cf33309f7d461b7510a9d93cb99",
    "success": true
}
```

Так же есть метод для получения текущего хеша, который можно сравнить
с хранящимся в системе, и понять изменились переводы или нет

Так же есть метод по удалению переводов, если передать ему алиас - то
удалит по алису, иначе удалит все переводы, нужно быть осторожным, в
ответ возвращает новый хеш
